# Cyberpunk 3D Website

A dark, cyberpunk-themed 3D animated website featuring:

## Features

- **3D Scene**: Powered by Three.js with custom GPU models
- **8 GPU Models**: Arranged in a circular formation representing your 8x RTX 3090 homelab
- **Particle System**: 2000+ floating particles in cyan/magenta colors
- **Abstract Shapes**: 5 wireframe torus shapes with random rotation
- **Mouse Interaction**: Camera follows your mouse movement
- **Cyberpunk Styling**: Dark background, neon effects, flickering header
- **Blog Content**: Displays your homelab build summary with stats
- **Social Posts**: Shows your last 5 tweets from @seroxdesigns

## Files

- `cyberpunk-3d-website.html` - Main website file
- `run-website.js` - Helper script with usage instructions

## How to Use

1. Open `cyberpunk-3d-website.html` in your browser
2. Move your mouse around to interact with the 3D scene
3. Scroll through the blog content and social posts sections

## Tech Stack

- Pure HTML/CSS/JavaScript
- Three.js for 3D rendering (CDN)
- No build process required

## Customization

- Edit the CSS variables at the top of the `<style>` block
- Modify the Three.js scene parameters in the script
- Update the blog content and social posts sections
